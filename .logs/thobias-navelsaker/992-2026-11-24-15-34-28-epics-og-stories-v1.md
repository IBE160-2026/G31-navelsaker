# Epics og stories v1

## 2026-11-24 kl. 15:34 — Thobias Navelsaker

### Oppgave
Lage epics og stories for Red Ball Express v1 med `bmad-create-epics-and-stories`. Brukeren ville ha forslag med kort begrunnelse og ta valgene selv. Seks punkter skulle avgjøres:
- inndeling og rekkefølge
- størrelse på stories (én branch og én PR)
- akseptansekriterier mot scenario A–E og EXPERIENCE.md
- sporbarhet fra FR til story til test
- hvor skalatest, importtest, rutetest, sammenligning av kjøringer, testplan og README hører hjemme
- når skjermbilder og video skal tas

Uklarheter skulle føres tilbake i dokumentene de gjelder. Fortsettelse av [ux-v1](993-2026-11-24-14-48-42-ux-v1.md).

### Plan
- Lese CLAUDE.md, issues.md, sesjonslogg 993, 995 og 997, PRD med addendum og memlog, arkitekturen med memlog, DESIGN.md, EXPERIENCE.md, key-screens og fasiten.
- Steg 1: kravoversikten i `epics.md` (FR, NFR, SM, AD-1–11, prosessrammer og UX-DR1–22). Akseptansekriteriene for FR-17 ble regnet mot `expected.json`, først med Node og så på nytt med Python via uv etter at brukeren spurte.
- Legge fram forslag til de seks punktene og tre uklarheter (U1 ikke-kjørte endringer, U2 utdatert setning i EXPERIENCE.md, U3 SM-2 dekker ikke UJ-2). Brukeren påpekte at forslaget var skrevet på engelsk, og det ble skrevet på nytt på norsk.
- Steg 2: epic-listen med spørsmål til brukeren. Brukeren valgte skjelettet først, BOM sammen med redigering, sammenligningen først i endrings-epicen og revisjonsteller.
- Steg 3: stories. Avansert elicitering (pre-mortem og grensetilfeller) ga PM1–PM4 og EK1–EK5. Alt ble tatt inn, og duplikate byggenumre avvises.
- Steg 4: sluttvalidering med skript (dekning av FR og UX-DR, henvisninger framover). Tre små funn (V1–V3) ble rettet.
- Tilbakeføring til PRD, arkitektur og EXPERIENCE.md, så AI-logg og commits.
